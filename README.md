# Snake-Game
This is a snake game. You will need to control the black snake to eat the food to a certain condition to win the game.

## Original settings:
### food color = red
### speed = medium
### win condition = a length of 10
(You can also change the settings before starting the game OWO )

## Keys:
### key_up = up
### key_down = down
### key_left = left
### key_right = right

Have Fun !!!!
